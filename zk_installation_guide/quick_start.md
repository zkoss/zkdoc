This chapter describes how to quickly start your first ZK application. Pick the setup that
matches the tools you already use — every option ends with the same running ZK page.

If you are not sure, use
**[First ZK App with Maven Archetype]({{site.baseurl}}/zk_installation_guide/create_and_run_your_first_zk_application_with_maven_archetype)**.
It needs only Java and Maven, and works the same on every operating system and in every IDE.

# Choose Your Setup

- [First ZK App with Maven Archetype]({{site.baseurl}}/zk_installation_guide/create_and_run_your_first_zk_application_with_maven_archetype) — command line, no IDE required
- [First ZK App with IntelliJ and ZKIdea]({{site.baseurl}}/zk_installation_guide/create_and_run_your_first_zk_application_with_intellij_and_zkidea) — includes the ZK plugin with ZUL completion and layout preview
- [First ZK App with Eclipse and Maven]({{site.baseurl}}/zk_installation_guide/create_and_run_your_first_zk_application_with_eclipse_and_maven)
- [First ZK App with Eclipse and ZK Studio]({{site.baseurl}}/zk_installation_guide/create_and_run_your_first_zk_application_with_eclipse_and_zk_studio)
- [First ZK App with Gradle]({{site.baseurl}}/zk_installation_guide/create_and_run_your_first_zk_application_with_gradle)
- [First ZK App with Spring Boot]({{site.baseurl}}/zk_installation_guide/create_and_run_your_first_zk_application_with_spring_boot)
- [First ZK App with Visual Studio Code]({{site.baseurl}}/zk_installation_guide/create_and_run_your_first_zk_application_with_visual_studio_code)
- [First ZK App with NetBeans and REM]({{site.baseurl}}/zk_installation_guide/create_and_run_your_first_zk_application_with_netbeans_and_rem)
- [First ZK App Manually]({{site.baseurl}}/zk_installation_guide/create_and_run_your_first_zk_application_manually) — no build tool, for understanding what the jars and `web.xml` actually do
